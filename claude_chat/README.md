# Claude Chat

Chat with Claude Code about your Home Assistant in a window that works like the Claude desktop app: chats on the left, streamed replies, readable approval cards, undo for every change, and a home screen that shows what needs attention in your home.

It runs the real Claude Code (through Anthropic's Agent SDK) on your Claude subscription, with the same access to Home Assistant as the Claude Terminal add-on.

See the Documentation tab for setup and use.
